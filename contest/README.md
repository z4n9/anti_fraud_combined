# Конкурсные материалы Family Guard

[Скачать полный комплект одним ZIP](Family_Bank_Family_Guard_Documents.zip): документация в Word, презентация PPTX, one pager RU/EN, техприложение и небольшие примеры CSV. Распакуйте архив целиком и откройте `00_START_HERE.docx` внутри папки комплекта.

Обновлено 15 октября 2026 для Caspian University, финал в Алматы. **Family Bank** — клиентский банк; **Family Guard** — добровольная защита и кабинет аналитика.

- [Pitch deck](Family_Guard_Pitch_Deck.pptx): 12 редактируемых слайдов 16:9, заметки докладчика и источники. Переход Fade по щелчку, без автоматического перелистывания.
- [Резюме RU](Family_Guard_Summary_RU.docx) и [summary EN](Family_Guard_Summary_EN.docx): по одной странице.
- [Единое техническое приложение](Family_Guard_Technical_Appendix_RU.docx): актуальный раздел 5 заявки.
- [Указатель тематического Word-комплекта](../docs/technical-appendix/00-index.docx): методика, данные, проверки, TRL. [Markdown-исходники](../docs/technical-appendix/README.md).

Материалы отражают добровольную защиту, фиксированный семейный кворум и банковское разрешение конфликта, независимый мониторинг мелких поступлений. Последние подтверждённые после ребрендинга проверки 15 октября: 379 backend-тестов прошли, 7 пропущены, 70 frontend-тестов прошли. Precision, recall и F1 не измерены. TRL 4 — самооценка. MoMTSim v2 атрибутирован по CC BY 4.0, искусственное восстановление времени раскрыто. Иллюстрация обложки создана ИИ.

Перед подачей нужны ФИО участников по форме вуза и публичный URL прототипа либо видео до пяти минут. Локальный адрес не является ссылкой для жюри. Режим показа и тайминг проверьте репетицией в используемой версии PowerPoint.
