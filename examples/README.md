# Данные для демонстрации

Для короткого показа загрузите `transactions_demo.csv`: семь собственных синтетических операций, проверенных сквозным сценарием.

Для расширенного показа доступен `MoMTSim_sample_prepared.csv`: 100 000 подготовленных операций. Источник: Denish Azamuke (2024), *Synthetic Mobile Money Transaction Dataset*, Mendeley Data, version 2, DOI [10.17632/zhj366m53p.2](https://doi.org/10.17632/zhj366m53p.2), [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Выборка, переименование полей, генерация идентификаторов и синтетическое восстановление времени выполнены командой проекта. Это демонстрационные данные; число сигналов правил не является точностью детектора. Подробнее — [атрибуция и преобразования](../docs/dataset-attribution.md).

Исходный большой CSV и альтернативная выгрузка сохраняются локально в `data/source-datasets/` и не входят в Git. Чтобы повторно подготовить выборку, скачайте исходник со [страницы версии 2](https://data.mendeley.com/datasets/zhj366m53p/2), сохраните под именем `MoMTSim_20240722202413_1000_dataset.csv` в этом каталоге и выполните из корня проекта:

```powershell
python scripts/prepare_momtsim_sample.py
```

Скрипт возвращает до указанного числа строк: при нехватке записей в отдельных шагах итог может быть меньше. Он удерживает исходные группы в памяти, поэтому подготовку большого источника выполняйте локально с достаточной памятью, а не на маленьком VPS. На сервер передавайте готовую выборку; её пригодность для выбранных ресурсов проверяется отдельным запуском.
