# Названия Family Bank и Family Guard

Редакция от 15 октября 2026 года. **Family Bank** — название клиентского банка. **Family Guard** — название добровольной семейной защиты и кабинета банковского аналитика. В заявке и презентации проект называется Family Guard, работающий в Family Bank.

## Совместимость существующего экземпляра

Ребрендинг меняет отображаемые названия и конкурсные материалы. Следующие технические идентификаторы сохранены, чтобы обычное обновление не потеряло данные и настройки:

| Идентификатор | Назначение |
| --- | --- |
| `frontend/aman`, `backend/app/risk_ledger` | Пути модулей исходного кода |
| `AMAN_*` | Переменные окружения существующего деплоя |
| `aman_session` | Cookie авторизации |
| Compose service `aman`, volume `aman-data` | Существующий сервис и постоянные данные |
| `aman_bank.db` | Имя банковской SQLite |
| `Aman-Test-0001!` и остальные `Aman-Test-…!` | Совместимые демонстрационные пароли из USER_GUIDE.md |
| `anti_fraud_arrt`, Git `anti_fraud_combined` | Директория проекта и адрес существующего репозитория |

Новый Docker-образ называется `family-bank-mvp:1.0.0`. Для обновления выполните `docker compose up --build -d --wait`, сохраняя прежний том. Старые пароли не заменяются автоматически. Новые карты используют название Family Gold; старые AMAN Gold отображаются как Family Gold через совместимый alias без изменения сохранённых строк, балансов или истории.

Исходные названия AMAN Bank и Risk Ledger могут встречаться только в явно обозначенной истории происхождения и технических идентификаторах. Соседние самостоятельные исходные проекты не переименовываются.
