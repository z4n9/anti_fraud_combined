## 3. Известные особенности и проблемы
1. **Отсутствие артефактов моделей в FraudBanc:**
   - В папке `FraudBanc/backend/artifacts` нет скомпилированных моделей CatBoost и Isolation Forest (только `.gitkeep`).
   - *Решение:* Антифрод запускается в режиме `rule-based fallback` на детерминированных правилах.
2. **PowerShell ExecutionPolicy для npm:**
   - Вызов `npm` напрямую блокируется Windows ExecutionPolicy.
   - *Решение:* Всегда вызывать `npm.cmd`.
3. **Docker Daemon:**
   - Docker CLI установлен, но Desktop daemon не запущен в текущий момент.
   - *Решение:* Запуск осуществляется локально через Python venv и npm dev без обязательного Docker.
