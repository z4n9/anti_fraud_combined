# Источник и преобразования MoMTSim

Проверено 11 октября 2026 года по [странице Mendeley Data](https://data.mendeley.com/datasets/zhj366m53p/2).

Denish Azamuke (2024). *Synthetic Mobile Money Transaction Dataset*, Version 2. Mendeley Data. DOI: [10.17632/zhj366m53p.2](https://doi.org/10.17632/zhj366m53p.2). Опубликовано 29 октября 2024 года. Лицензия: [Creative Commons Attribution 4.0 International — CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).

Источник описывает данные как синтетические мобильные денежные операции, созданные MoMTSim. Его описание статистической близости к исходным данным не является оценкой нашего антифрода. Автор источника не заявлял одобрения AMAN Guard.

Локальный исходный CSV — MoMTSim_20240722202413_1000_dataset.csv, 366 397 921 байт, 4 225 958 записей. Пользователь указал, что скачал его со страницы версии 2. Побайтовая сверка с повторной загрузкой из источника не выполнялась.

Производная выборка в examples/MoMTSim_sample_prepared.csv подготовлена локальным scripts/prepare_momtsim_sample.py. Преобразования: фильтрация неположительных сумм, выборка по шагам и типам операций, генерация идентификаторов, переименование полей под каноническую схему, сохранение метки isFraud как transaction_fraud_label. Время реконструировано искусственно: шаг трактуется как час, старт выбран 2024-07-22 UTC, добавлено распределение внутри часа. Это предпосылки скрипта, а не подтверждённые реальные timestamps; они влияют на временные признаки. Проверка предпосылок по статье/документации MoMTSim остаётся открытой.

При распространении выборки сохраняйте имя автора, название, DOI/ссылку на исходник, ссылку на CC BY 4.0 и описание изменений. Исходные данные имеют лицензию CC BY 4.0; этим документом не устанавливается лицензия всего программного репозитория. Минимальный examples/transactions_demo.csv — отдельный собственный синтетический пример.
