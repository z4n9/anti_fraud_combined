# Техническое приложение: Family Guard

Основной комплект в Word: [указатель](00-index.docx), [методика](01-method.docx), [данные и исходники](02-data-and-source.docx), [метрики и тест-кейс](03-validation.docx), [план TRL](04-roadmap-trl.docx). Markdown ниже сохранён как исходник.

Конкурсная версия, обновлена 15 октября 2026 года. Family Guard объединяет клиентский Family Bank, семейное согласование переводов и кабинет аналитика Family Guard.

Читайте четыре раздела по порядку; каждый отвечает отдельному пункту технического приложения:

| Файл | Содержание |
| --- | --- |
| [01-method.md](01-method.md) | Методика, модель риска и принятие решения |
| [02-data-and-source.md](02-data-and-source.md) | Датасеты, лицензия, исходники и воспроизводимость |
| [03-validation.md](03-validation.md) | Подтверждённые проверки, метрики и тест-кейс |
| [04-roadmap-trl.md](04-roadmap-trl.md) | Текущая готовность, ограничения и план доработки |

Комплект сверяет исходники и существующие отчёты. Указанные тесты выполнены в даты исходных отчётов; сборка документации не является новым прогоном.
