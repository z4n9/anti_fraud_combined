## 2. Проверенные команды проверки бэкенда

### Активация виртуального окружения
```powershell
# Создание venv (если не создан):
python -m venv .venv

# Установка базовых зависимостей банковского модуля:
.\.venv\Scripts\python.exe -m pip install fastapi uvicorn SQLAlchemy pydantic httpx pytest

# Установка расширенных аналитических зависимостей:
.\.venv\Scripts\python.exe -m pip install numpy pandas scikit-learn python-multipart
```

### Запуск тестов банковского модуля
Все 32 теста `anti_fraud_1` проверены и гарантированно проходят:
```powershell
.\.venv\Scripts\python.exe -m pytest anti_fraud_1\backend\tests -v
```
**Результат:** `32 passed, 1 warning in 41s`.
Проверяемые сценарии:
- Защита от овердрафта и отрицательных сумм.
- Точность дробных сумм (тиыны).
- Идемпотентность повторных запросов (`Idempotency-Key`).
- Конкурентные переводы и предотвращение двойного списания.
- Атомарный откат транзакции при сбое записи истории.
- Полный сценарий «Бабушка — Сын» (приглашение, верификация Mock eGov, подтверждение из аккаунта сына).
- Запрет подтверждения отправителем или посторонним пользователем.
- Отказ дочери и изоляция финансовых данных.
- Аддитивные миграции базы SQLite с сохранением данных.

## 4. Сценарий ручной браузерной проверки (Multi-Session Flow)
1. **Подготовка двух независимых браузерных профилей:**
   - Окно 1 (Обычный режим): Бабушка (Амина Омарова, `TEST0006`, пароль `Aman-Test-0006!`).
   - Окно 2 (Режим инкогнито / другой браузер): Сын (Марат Омаров, `TEST0003`, пароль `Aman-Test-0003!`).
2. **Семейная защита:**
   - В Окне 1 открыть настройки защиты, ввести ИИН сына `TEST0003`, нажать «Проверить родство» (Mock eGov), затем «Отправить приглашение».
   - В Окне 2 обновить профиль сына, открыть входящие приглашения, нажать «Принять».
   - В Окне 1 убедиться, что баннер защиты стал активным.
3. **Проверка рискованного перевода:**
   - В Окне 1 попытаться отправить нетипично крупную сумму новому получателю.
   - Система переводит платёж в статус «Требуется подтверждение родственника». Деньги не списаны.
   - В Окне 2 сын видит запрос с реквизитами и объяснением причин риска.
   - Сын нажимает «Одобрить перевод».
   - Деньги списываются у бабушки и поступают получателю.
