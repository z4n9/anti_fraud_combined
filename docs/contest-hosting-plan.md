# Площадка для публичного конкурсного прототипа

Пользователь выбрал публичный прототип и попросил снизить бюджет первоначального предложения $24/месяц. Обновлённая рекомендация от 11 октября 2026: **DigitalOcean Basic Droplet, Regular, Ubuntu LTS, 1 vCPU / 2 ГиБ RAM / 50 ГиБ SSD за $12/месяц**, один экземпляр AMAN Guard через существующий Docker Compose. Это предложенная конфигурация, а не уже созданный сервер. Начальный показ — банковские сценарии и минимальный CSV; пригодность для 100 000 операций необходимо измерить, она пока не подтверждена нагрузочным тестом. Если вуз предоставляет Linux VPS с аналогичными ресурсами, его можно использовать вместо платного сервера.

## Сравнение

| Вариант | Основание | Вывод для текущей версии |
| --- | --- | --- |
| DigitalOcean VPS | Полный контроль ОС и диска, запуск имеющегося Compose | Рекомендуется, чтобы сохранить уже проверенную схему nonroot и named volume; HTTPS и обслуживание настраиваются командой |
| Render с платным сервисом и persistent disk | [Диск](https://render.com/docs/disks) сохраняет данные, доступен одной инстанции; бесплатный сервис без такого диска не подходит для сохранения SQLite | Возможен, но нужно отдельно проверить права каталога, параметры запуска и доверие reverse proxy |
| Railway Hobby с volume | [Volume](https://docs.railway.com/volumes/reference) поддерживает постоянное хранение; документация предупреждает о правах при nonroot UID | Возможен после адаптации прав; не применять рекомендованный RUN_UID0 автоматически вместо проверки нынешней схемы безопасности |

Проверенные [тарифы DigitalOcean](https://www.digitalocean.com/pricing/droplets): Basic Regular 1 ГиБ/1vCPU/25ГиБ — $6/месяц; 2ГиБ/1vCPU/50ГиБ — $12/месяц; 4ГиБ/2vCPU/80ГиБ — $24/месяц. Для конкурса предлагается вариант $12. Это цена вычислительного сервера по состоянию проверки, без домена, дополнительных backup-услуг, налогов и иных платных опций. При двух полных месяцах: $24 за вычисления; валютный пересчёт и итог оплаты не фиксировались. Вариант $6 можно рассмотреть для банковского демо и семи строк, после проверки памяти; большие выгрузки на нём не обещаем. Docker-образ можно собирать локально и переносить, чтобы не тратить память VPS на сборку фронтенда. [Railway](https://railway.com/pricing) Hobby имеет минимальное использование $5 с оплатой превышения, это не фиксированная цена всей инфраструктуры.

## Что понадобится от владельца

Согласованный бюджет, аккаунт выбранной площадки, созданный сервер и доступ по SSH с ключом; домен/поддомен для HTTPS либо согласованный вариант адреса. Приватные ключи и пароли не вставлять в документы заявки. Сервер и платные услуги пока не заказывались. Наличие готового университетского VPS может заменить покупку DigitalOcean без изменения приложения.

## План развёртывания после получения доступа

1. Утвердить конкурсную версию: проверить незакоммиченные изменения маппинга и выборки, результаты и лицензию; не публиковать весь350МиБCSV как часть Docker-образа.
2. Подготовить сервер с Docker/Compose, отдельную демонстрационную базу и резервное копирование по DEPLOYMENT.md.
3. Разместить HTTPS reverse proxy перед loopback8000; настроить точный AMAN_PUBLIC_ORIGIN, Secure-cookie и доверие только реальному адресу прокси. Конкретные IP/конфигурация выбираются на сервере, wildcard trust не допускается.
4. Дать жюри отдельный демонстрационный доступ и тестовые аккаунты; сохранить демонстрационные ограничения в интерфейсе. Для просмотра не использовать локальную рабочую SQLite владельца.
5. Проверить /api/readiness, вход из внешнего браузера, семейное согласование/конфликт, банковский аудит, CSV и сохранение после перезапуска. Ограничить расход хранилища/параллельные загрузки исходя из замера; не считать прежний локальный smoke доказательством внешнего деплоя.
6. Проверить URL с другой сети без аккаунта хостинга, затем вставить фактическую ссылку в CONTEST_SUBMISSION.md. Сохранить доступ минимум до нужного финала в ноябре и отдельно согласовать дату отключения.
