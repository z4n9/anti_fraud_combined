## Этап 4. Проверка перевода и семейное подтверждение (ЗАВЕРШЁН)
**Зависимости:** Этап 2, Этап 3.
- [x] POST /api/transfers рассчитывает риск сервером и сохраняет снимок решения.
- [x] Отдельные TransferRequest: pending_approval без списания, blocked_no_trusted без автоматического исполнения, фиксированные реквизиты и Idempotency-Key.
- [x] GET /api/transfers/requests и /pending-requests; POST /api/transfers/requests/{id}/approve, /reject, /cancel. Используется ID запроса, отдельно от проводки.
- [x] Проверены запрет отправителю/постороннему, подмена реквизитов, отзыв/замена согласия, гонки решений, откат ошибок и отсутствие чужого баланса в ответах.
- [x] Истечение через 24 часа, проверка доступных средств и зафиксированных карт при одобрении; повторное решение не исполняет перевод повторно.
- [x] AMAN отображает риск, ожидание, блокировку и очереди; семейные приглашения сохранены.
- [x] Сквозной HTTP сценарий на отдельной временной SQLite: бабушка -> ожидание без списания -> сын одобряет -> один дебет/кредит. Общий прогон 122 passed и последний добавленный тест отдельно 1 passed; текущая коллекция 123 теста.
- **Критерий завершения:** семейное решение определяет исполнение конкретного перевода, денежная запись атомарна. Визуальная браузерная проверка остаётся невыполненной из-за недоступности браузера.
