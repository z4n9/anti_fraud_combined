## Этап 4. Сцепка перевода и семейного подтверждения (Core Integration)
**Зависимости:** Этап 2, Этап 3.
- [ ] Интеграция проверки риска в пайплайн `POST /api/transfers`.
- [ ] Добавление статуса `pending_approval` для транзакций высокого риска.
- [ ] Реализация эндпоинтов:
  - `GET /api/transfers/pending-requests` (список запросов на подтверждение для родственника).
  - `POST /api/transfers/{id}/approve` (атомарное списание/зачисление только авторизованным родственником).
  - `POST /api/transfers/{id}/reject` (отклонение операции).
- [ ] Тесты на безопасность:
  - Попытка подтверждения отправителем -> `403`.
  - Попытка подтверждения посторонним лицом -> `403`.
  - Попытка изменения суммы после одобрения -> аннулирование.
  - Поведение при отсутствии доверенного лица -> блокировка операции.
- **Критерий завершения:** Полный сквозной тест: Бабушка -> Перевод высокого риска -> Родственник одобряет -> Балансы меняются.
