# Обновление интерфейса Family Bank

Актуальная продуктовая редакция: **Family Bank / Family Guard**, 15 октября 2026. Последний полный прогон после ребрендинга: **379 passed, 7 skipped** backend и **70 passed** frontend, lint и build прошли. Мониторинг получателей проверен через реальную загрузку и браузер. Числа и ограничения прежних дат ниже относятся к истории проверок и не заменяют текущий контракт [project-context.md](project-context.md), ADR-016 и ADR-017. Совместимость названий — [branding.md](branding.md).

14 октября 2026 года перенесено оформление из `anti_fraud_1/frontend`, версия источника `90b3cb7dc292b58e73f34af768b0df75ec2889e8`.

## Изменения

- Голубая палитра C2, типографика, кнопки, карточки, светлая и тёмная темы, адаптивная навигация.
- Главная с плитками действий, картой и семейным баннером. Прежние переходы доступны через плитки, нижнюю навигацию и кнопку карты.
- Семейная иллюстрация `family-care.png` и SVG из исходного проекта, оформление семейного экрана.
- Индикатор существующих этапов перевода и версии CSS/JS для обновления браузерного кеша.

Изменены только файлы `frontend/aman`. API-клиент, авторизация, обработчики событий, переводы, AntiScam, голоса родственников, задержка отключения и ссылка на Family Guard сохранены. Backend и `frontend/analyst` не изменялись. Несовместимые JS-адаптеры нового исходника для ML, детей и доверенных лиц не переносились.

## Проверки

- `node --check frontend/aman/app.js` прошёл.
- Независимое сравнение AST с Git HEAD подтвердило изменение только шести визуальных шаблонов и добавление двух UI-хелперов; API, обработчики и проверки сессии сохранены, функции не удалены.
- Временный headless Edge прогон: 10 сценариев на фактических ширинах 360, 390 и 900 px. Проверены вход и ссылка на аналитика, главная, семейная защита, перевод, подтверждение, запросы и результат, профиль, светлая/тёмная темы и отсутствие горизонтального переполнения. Проверены поля AntiScam, действия голосования/отмены, недоступность исполнения макетного карточного перевода и привязка запросов к аккаунту.
- Сетевые ответы для браузерного прогона получены через текущий FastAPI TestClient на отдельной временной SQLite; списки запросов для проверки разметки голосов дополнены синтетическими UI-данными. Рабочая база не использовалась. Основные HTML/CSS/JS и обе иллюстрации отдавались с HTTP 200.
- Скриншоты просмотрены, исправлен цвет текста основных кнопок в тёмной теме. Служебные страницы, профиль браузера и отчёт находятся в игнорируемой `.test-tmp/aman-ui-20261014`.

Это проверка переноса интерфейса. Новый полный backend-прогон и новая проверка Docker-образа в рамках этой задачи не выполнялись.

Для существующего Docker-запуска обновление попадёт в контейнер после пересборки: `docker compose up --build -d --wait`. Удалять том не требуется. При локальном запуске достаточно обновить страницу; текущие CSS/JS используют новый параметр версии.
